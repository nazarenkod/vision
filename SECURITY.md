# Безпека

## Повідомити про вразливість

Не створюйте публічну задачу. Напишіть власнику продукту Vision у банку (контакт — у
[пакеті передачі](docs/handover/README.md#контакти)) з описом, кроками відтворення й версією
(коміт). Підтвердження — протягом 2 робочих днів, оцінка й план виправлення — протягом 5.

## Підтримувані версії

Виправлення безпеки випускаються для останньої поставки (див. [CHANGELOG](CHANGELOG.md)).

## Як влаштований захист

Огляд для ІБ — [docs/handover/security.md](docs/handover/security.md): дані, вхід, доступ,
мережа, перевірки, залишкові ризики. Звіти: [аудит](docs/security/audit-2026-11-04.md),
[SAST](audit/report-sast-2026-11-09.md).

## Для розробників

- Секрети — лише в `.env.demo` на сервері, ніколи в git.
- Токени Jira лише записуються, рядок `User` ніколи не віддається цілком.
- Міграції лише додавальні, без видалень даних.
- Перед злиттям — `python3 -I scripts/verify.py` і `npm audit` у змінених пакетах.
