# ADR-0001: Форк як монорепозиторій із git subtree

- **Статус:** Accepted
- **Дата:** 2026-10-24

## Контекст

Upstream VRT складається з окремих репозиторіїв backend, frontend і sdk-java. Нам потрібні
зміни в усіх трьох одночасно (нове поле в SDK, обробка на бекенді, UI), а оновлення з upstream
мають лишатися можливими.

## Рішення

Один репозиторій `vision` з папками `backend/`, `frontend/`, `sdk-java/`, імпортованими через
`git subtree add --squash` з upstream master. Робоча гілка `mvp/demo` пушиться в `vision/main`.
Remote `origin` — upstream, туди не пушимо.

## Наслідки

- Одна зміна охоплює всі шари й перевіряється разом.
- Оновлення з upstream — `git subtree pull --squash` по кожній папці; конфлікти можливі там, де
  ми змінювали код upstream, тож такі зміни робимо мінімальними й локалізованими.
- Ліцензія й NOTICE upstream зберігаються.
