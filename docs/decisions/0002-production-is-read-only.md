# ADR-0002: Робочий VRT лише читається

- **Статус:** Accepted
- **Дата:** 2026-10-24

## Контекст

Vision стоїть на тій самій машині, що й робочий VRT, і працює на копії його бази й картинок.
Пошкодити прод не можна за жодних умов: це вимога власника.

## Рішення

- Прод лише читається: `pg_dump` (транзакція для читання, `nice 19`), кілька `SELECT`, копія або
  жорсткі посилання на файли. Vision ніколи не пише у файли чи базу проду.
- Усі команди compose — лише через `scripts/vision.sh` з жорстко заданим проєктом `vision` і
  перевіркою, що в проєкті немає чужих контейнерів.
- Запас диска перед копіюванням і збиранням, обмеження CPU й пам'яті для Vision, підтвердження
  `yes` перед руйнівними діями.

## Наслідки

- Будь-який новий скрипт мусить іти через `scripts/lib/vision-safety.sh`.
- Перевірка — «відбиток» проду до і після (хеші таблиць і файлів), див. [011](../specs/011-deployment-safety/spec.md).
- Ціна: зайвий крок при кожній команді, а діагностику через `docker compose` напряму не робимо.
