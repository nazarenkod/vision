# ADR-0003: Лише додавальні зміни схеми

- **Статус:** Accepted
- **Дата:** 2026-10-24

## Контекст

Vision працює на копії бази upstream VRT, а згодом може працювати на живій базі або поруч із
новими версіями upstream.

## Рішення

Міграції лише додають: нові таблиці, nullable-колонки без значень за замовчуванням, індекси.
Без змін enum, без видалень і перейменувань, без перетворень наявних даних у міграції. Перенесення
старих даних, якщо потрібне, робить застосунок при старті, і воно ідемпотентне (приклад —
`moveIssueStates`).

## Наслідки

- Upstream VRT міг би працювати на базі після міграцій Vision.
- Рішення «старого формату» живуть поруч із новими, поки їх не перенесено (`A11yIssueState`).
- JSON-налаштування (`uiTreeSettings`) додаються без міграцій; парсер мусить терпіти старі й
  биті записи.
