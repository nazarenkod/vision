# ADR-0004: SDK — upstream плюс одне поле

- **Статус:** Accepted
- **Дата:** 2026-10-25

## Контекст

Автотести команд уже використовують upstream Java SDK, і версія прописана в `pom.xml`. Власник
вимагає, щоб у SDK змінилось лише одне: додався необов'язковий параметр з XML.

## Рішення

`TestRunOptions.uiTree` — єдина зміна відносно upstream 4.3.1. SDK стискає XML (gzip + base64) і
надсилає в тому ж `POST /test-runs`. Розбір, щільність, формат визначає сервер. Jar лежить у
`dist/sdk-java/` (версія `4.3.1-vision.N`), підключається вручну.

## Наслідки

- Наявні тести працюють без змін; дерево додається одним рядком.
- Те, що могло б бути в SDK (зручний `trackDriver`, `failOnNewA11yIssues`), лишаємо серверу або
  CLI.
- Сервер мусить сам визначати формат і щільність (з оцінкою, якщо `deviceDensity` немає).
