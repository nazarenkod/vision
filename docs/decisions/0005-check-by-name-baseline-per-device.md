# ADR-0005: Перевірка за назвою, еталон на пристрій

- **Статус:** Accepted
- **Дата:** 2026-10-25

## Контекст

У кожного екрана є еталони на емуляторі або симуляторі та на BrowserStack-пристрої. Порівнювати
пікселі між різними пристроями не можна, а правила й рішення хочеться мати одні на екран.

## Рішення

Перевірка = назва тесту + `customTags`. Варіації upstream (еталон на кожен профіль пристрою)
лишаються як є. Правила елементів і рішення щодо доступності належать перевірці. UI групує
пристрої перевірки й приймає їх разом.

## Наслідки

- Без міграції: наявні дані групуються за назвою.
- Пристрій без свого еталона все одно перевіряється на доступність і «не той екран» відносно
  еталона іншого пристрою.
- Назва тесту стала значущою: перейменування = нова перевірка.
