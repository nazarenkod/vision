# ADR-0006: Порівняння між пристроями — лише довідка

| | |
|---|---|
| Статус | Superseded by ADR-0016 |
| Дата | 2026-10-25 |
| Хто вирішив | Дмитро Назаренко |

## Контекст

Порівняння дерев різних пристроїв ловить зниклі елементи й інші підписи, але розкладки
різняться (елементи за межами екрана, інші розміри). Власник оцінив логіку як складну й поки
ненадійну.

## Чинники рішення

- Не створювати хибних «падінь».
- Зібрати дані, щоб вирішити пізніше.

## Розглянуті варіанти

1. Порівняння впливає на статус
2. Лише довідка + журнал рішень
3. Не робити

## Рішення

Друга опція. Вкладка Devices показує розбіжності, статус не змінюється. Результат і рішення
рев'юера пишуться в `CrossDeviceCheck`.

## Наслідки

- Добре: рішення про довіру — за даними (SQL у [DEMO.md](../../DEMO.md)).
- Погано: поки це додаткова вкладка, яку можна не відкривати.

## Як перевіряємо

Раз на місяць — запит з DEMO.md; переглянути ADR, коли буде ≥ 200 рішень.

## Варіанти: за і проти

### 1. Порівняння впливає на статус

- Добре: ловить більше.
- Погано: хибні падіння, недовіра до інструмента.

### 2. Лише довідка + журнал рішень

- Добре: без шкоди; дані для оцінки.
- Погано: розбіжності можна не помітити.

### 3. Не робити

- Добре: простіше.
- Погано: немає даних, щоб колись вирішити.
