# ADR-0009: База Vision — джерело правди, Jira — дзеркало

- **Статус:** Accepted
- **Дата:** 2026-10-26

## Контекст

Баги заводять кілька людей одночасно, інколи руками або з іншої інсталяції. Пошук у Jira
повільніший, обмежений правами токена й може не відповісти. Відв'язаний баг не повинен
прив'язуватися знову.

## Рішення

- Рішення живуть у базі Vision (`A11yProblem`, журнал `A11yDecision`). «Замок» — унікальний
  ключ у базі.
- Jira дзеркалює рішення мітками: ID і маркери фактів при створенні та Link,
  `a11y-unlinked-<id>` замість маркерів при Unlink.
- Vision шукає в Jira за ID або маркерами перед заведенням і при відкритті рев'ю (кеш 10 хв,
  таймаут 5 с), і лише доповнює базу знайденим. Відв'язаний у журналі баг автоматично не
  прив'язується ніколи.

## Наслідки

- Без Jira Vision працює повністю; збій міток — попередження, а не помилка.
- Баги, заведені поза Vision, знаходяться лише з ID або повним набором маркерів.
- Журнал — основа для аудиту й майбутньої аналітики рішень.
