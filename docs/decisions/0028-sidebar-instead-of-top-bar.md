# ADR-0028: Навігація — бічне меню з підписами замість верхньої смуги й рейки іконок

| | |
|---|---|
| Статус | Proposed |
| Дата | 2026-11-05 |
| Хто вирішив | Дмитро Назаренко |

## Контекст

Дизайн-ревю 2026-11-03 ([046](../specs/046-design-review-refresh/spec.md)) знайшло дві
навігації: рейку з шести іконок без підписів, набір яких змінюється між сторінками, і верхню
смугу з мовою, темою, допомогою й аватаром. Профіль доступний двічі, а версія (REQ-041-04)
займає місце у смузі, яка більше нічого не несе.

## Чинники рішення

- Новачок має знаходити Baselines та Insights без підказок.
- Набір пунктів не повинен стрибати між сторінками.
- Порівнянню й таблицям потрібна вертикаль: смуга забирає 56 px з кожного екрана.

## Розглянуті варіанти

1. Лишити рейку й смугу, додати підказки.
2. Бічне меню 232 px з підписами; мова, тема, профіль — у меню акаунта; верхньої смуги немає.
3. Лише верхня смуга з вкладками.

## Рішення

Обрано варіант 2, бо він дає підписи й сталий набір пунктів і повертає 56 px вертикалі.
Нижче 1100 px меню згортається до іконок з підказками.

## Наслідки

- Добре: одне місце для всієї навігації; нові сторінки додають пункт у меню, а не кнопку в кут.
- Погано: 232 px ширини на широких екранах; тести й тур, що шукали шапку, переписуються.
