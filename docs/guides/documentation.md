# Як писати документацію

## Поступове розкриття

Читач (людина чи агент) спершу бачить мінімум, а по посиланнях отримує стільки деталей, скільки
потрібно для задачі.

| Рівень | Файли | Обсяг | Що там |
|---|---|---|---|
| 0 | `AGENTS.md` (корінь і пакети), `CLAUDE.md` | до ~120 рядків | правила, що діють завжди; команди; куди далі |
| 1 | `docs/README.md`, `product/`, `architecture/overview.md` | 1–2 екрани | карта, терміни, загальна будова |
| 2 | `specs/`, `decisions/`, `architecture/data-model.md`, `api.md`, `guides/` | скільки потрібно | деталі однієї теми |

Правила:
- **Рівень 0 — лише те, що потрібно в кожній задачі.** Деталь, потрібна раз на місяць, іде на
  рівень 2 і отримує посилання.
- **Кожен документ починається з того, що це і коли його читати**, далі — найважливіше.
- **Один факт — одне місце.** Решта посилається на нього. Команди — в `AGENTS.md` і
  `testing.md`; поведінка — у специфікації; «чому» — в ADR.
- **Посилання замість копій.** Скопійований текст розходиться з оригіналом.
- **Конкретно:** шляхи файлів, назви функцій, точні команди, числа з коду (48 dp, 10 хв).
- Таблиці — для переліків; списки — для кроків; абзаци — для пояснень «чому».

## Хто що оновлює

| Сталося | Онови |
|---|---|
| Нова або змінена поведінка | `spec.md` фічі: вимоги, трасування, статус |
| Рішення з наслідками або обмеження | новий ADR + рядок у `decisions/README.md` |
| Нова таблиця, колонка, файл, ендпоінт | `architecture/data-model.md`, `api.md` |
| Нова команда, пастка, правило пакета | `AGENTS.md` пакета |
| Змінилось розгортання чи налаштування для користувача | `DEPLOY.md` (рос.), за потреби `DEMO.md` |
| Новий термін | `product/glossary.md` |

## Мова

- Документація для команди — українською. `DEPLOY.md` лишається російською, поки його так
  читає людина, що розгортає; `DEMO.md` — англійською для показу.
- Ідентифікатори, назви полів, команди й тексти інтерфейсу — як у коді, англійською.

## Перевірка посилань

```bash
python3 - <<'PY'
import re, pathlib
for md in pathlib.Path('.').rglob('*.md'):
    if 'node_modules' in md.parts: continue
    for link in re.findall(r'\]\(([^)#\s]+)', md.read_text()):
        if link.startswith('http'): continue
        if not (md.parent / link).exists(): print(f'{md}: {link}')
PY
```
