## Контекст і проблема

Автотести вже викликають upstream Java SDK, а версія прописана в `pom.xml` команд. Будь-яка зміна
API SDK змусила б переписувати тести. Щоб працював аналіз дерева, SDK має надсилати page source.

## Користувацькі історії

### US-1 (P1): Додати дерево одним рядком

Як автоматизатор, я хочу додати page source до наявного виклику `track(...)` одним параметром, щоб
отримати аналіз дерева без переписування тестів.

- **Незалежна перевірка:** замінити jar, додати `uiTree(driver.getPageSource())`, прогнати тест.
- **Сценарії приймання:**
  1. **Дано** тест з upstream SDK, **коли** jar замінено на Vision-SDK без інших змін, **тоді**
     тест працює як раніше.
  2. **Дано** параметр `uiTree`, **коли** тест надсилає знімок, **тоді** у Vision з'являються
     перевірки дерева.

## Вимоги

| ID | Історія | Вимога |
|---|---|---|
| REQ-012-01 | US-1 | SDK ПОВИНЕН відрізнятися від upstream 4.3.1 лише необов'язковим параметром UI-дерева. |
| REQ-012-02 | US-1 | КОЛИ дерево передано, SDK ПОВИНЕН надсилати його стиснутим у тому ж запиті, що й знімок. |
| REQ-012-03 | US-1 | КОЛИ дерево не передано, SDK ПОВИНЕН надсилати запит, ідентичний upstream. |
| REQ-012-04 | US-1 | Сервер upstream ПОВИНЕН приймати запит з деревом, ігноруючи його. |
| REQ-012-05 | US-1 | SDK ПОВИНЕН працювати на Java 11+ і підключатися до Maven-проєкту без корпоративного репозиторію. |
