## Контекст і проблема

- Vision вміє лише один спосіб входу: локальні акаунти, LDAP або SSO. Банку потрібні корпоративний
  вхід і локальні акаунти разом. Налаштування LDAP і SSO зараз ще й не доходять до API з
  розгортання.
- Пароль можна підбирати без обмежень, а пароль локального акаунта може бути будь-яким.
- Помилки API віддають stack trace сервера, API відповідає будь-якому сайту, документація API
  відкрита.

## Користувацькі історії

### US-1 (P1): Корпоративний вхід і локальні акаунти разом

Як адмін, я хочу, щоб люди входили через LDAP або SSO банку, а ті, кого немає в каталозі, —
локальним акаунтом, щоб усі працювали в одному Vision.

- **Незалежна перевірка:** з увімкненим LDAP чи SSO увійти і корпоративним акаунтом, і
  локальним, який створив адмін.
- **Сценарії приймання:**
  1. **Дано** увімкнений LDAP чи SSO і локальний акаунт від адміна, **коли** обидва входять,
     **тоді** обидва в системі.

### US-2 (P1): Пароль не підібрати

Як власник сервісу, я хочу, щоб пароль не можна було підбирати і щоб локальні паролі були
довгими, щоб акаунти не зламали перебором.

- **Незалежна перевірка:** 5 разів увести хибний пароль: наступні 15 хвилин вхід для цього email
  відмовляє навіть із правильним паролем.
- **Сценарії приймання:**
  1. **Дано** 5 невдалих спроб для email, **коли** людина пробує ще, **тоді** бачить «спробуйте
     через 15 хвилин».

### US-3 (P1): API не віддає зайвого

Як власник сервісу, я хочу, щоб API не показувало внутрішніх подробиць і відповідало лише
своєму інтерфейсу, щоб сканер безпеки банку не знайшов витоків.

- **Незалежна перевірка:** викликати API з помилкою і з чужого сайту: без stack trace, чужому
  сайту відповідь не дістається, документація вимкнена.

## Граничні випадки

- Блокування для неіснуючого email → таке саме, як для наявного (REQ-045-03).
- SDK і CLI входять API-ключем → блокування входу їх не стосується.
- Наявний короткий пароль → вхід працює; змінити на короткий не можна (REQ-045-04).

## Поза межами

- Двофакторна автентифікація; LDAP і SSO одночасно; обмеження за IP-адресою.
