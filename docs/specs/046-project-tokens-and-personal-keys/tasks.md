# 046 — Задачі

Гілка `claude/046-project-tokens-spec`, окремо від редизайну. Бекенд (T1–T7) не чіпає файлів
інтерфейсу. Інтерфейс (T8–T9) — після того, як редизайн злито в цю гілку.

- [ ] **T1** (REQ-046-12, 15, 16) Міграція й схема: таблиця `ProjectToken`, `Build.projectTokenId`;
  `npx prisma generate`, фікстури `Project`/`Build` у тестах.
  - Файли: `backend/prisma/schema.prisma`, нова міграція.
  - Готово, коли: міграція лише додавальна (коментар чому), `tsc` і `npm test` зелені.
- [ ] **T2** [P] (REQ-046-07, 11, 13) Чисті функції: `credentialOf`, генерація `vp_…`, кінець,
  перевірка назви, `shouldTouch`.
  - Файли: нові backend/src/auth/credentials.ts, backend/src/projects/project-tokens.ts + spec.
  - Готово, коли: unit-тести з дизайну зелені.
- [ ] **T3** (REQ-046-06, 14, 16, 22) `CredentialsService.resolve`: сесія, персональний ключ
  активної людини, проєктний токен (не відкликаний), `lastUsedAt`.
  - Готово, коли: тести сервісу з моками Prisma зелені.
- [ ] **T4** (REQ-046-02, 03, 20, 23, 24, 25) `PersonGuard`, `SdkGuard`, `@SignedInOnly()`;
  `RoleGuard` бере визначеного guard-ом. Заміна guard-ів у всіх контролерах, позначки на
  облікових і адмін-маршрутах; старі guard-и прибрати.
  - Готово, коли: тест маршрутів перебирає кожен маршрут з JWT, ключем editor-а, ключем guest-а,
    ключем адміна й проєктним токеном і очікує відповіді з дизайну; `file-links` тест зелений.
- [ ] **T5** (REQ-046-04) `ProjectAccessInterceptor`: проєктний токен — лише свій проєкт, `403`.
  - Готово, коли: тест інтерсептора й тест маршрутів зелені.
- [ ] **T6** (REQ-046-05, 08) Автор збірки: `userId` або `projectTokenId` у `findOrCreate`;
  `BuildDto` віддає автора (ім'я людини або назву токена, без email і ключів).
  - Готово, коли: тест контролера й e2e з токеном зелені.
- [ ] **T7** (REQ-046-10…15) Маршрути токенів проєкту й `ProjectTokensService`.
  - Готово, коли: тести сервісу й маршрутів зелені; токен повністю лише у відповіді створення.
- [ ] **T8** (REQ-046-05, 10, 11, 13, 14) Інтерфейс: розділ «Токени для SDK» у налаштуваннях
  проєкту, автор в огляді збірки, підказка в картці API-ключа; ключі словника en/uk;
  Playwright-тест розділу й оновлені еталони скриншотів.
  - Залежить від: злиття редизайну в цю гілку.
- [ ] **T9** [P] (REQ-046-20, 21) e2e: погодження й баг з персональним ключем editor-а, відмова
  guest-у; документація API (`docs/architecture/api.md`), словник (`docs/product/glossary.md`:
  проєктний токен), DEMO/DEPLOY, крок 6 плану переходу — «токен проєкту в CI».
- [ ] **T10** Документація: «Перевірка вимог» у design.md — трасування `шлях › назва`; spec →
  `Implemented`; ADR-0028 → `Accepted`; рядок модулів у `backend/AGENTS.md`.
- [ ] **T11** `/verify`: тести, типи, лінт, еталони скриншотів, `scripts/check-docs.py`,
  контрольний сценарій з jar SDK на проєктному токені.
