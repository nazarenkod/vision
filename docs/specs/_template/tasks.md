# NNN — Задачі

Кожна задача невелика (до кількох годин), має перевірку і посилається на вимоги. Задачі, що
не залежать одна від одної й не чіпають тих самих файлів, позначені `[parallel]`: їх можна
віддати окремим агентам.

- [ ] **T1. …** (REQ-NNN-01)
  - Файли: …
  - Готово, коли: тест `…` зелений
- [ ] **T2. …** (REQ-NNN-02) `[parallel]`
  - Файли: …
  - Готово, коли: …
- [ ] **T3. Документація** — статус spec → `Implemented`, трасування заповнене, DEPLOY.md/DEMO.md
  оновлені, якщо змінилась поведінка для користувача.
- [ ] **T4. Перевірка** — `/verify`: тести, типи, лінт, еталони скриншотів, сценарій із
  критеріїв приймання.
